# ux-method

Метод проектирования взаимодействия человека с системой через интерфейс. Ядро общее для любой задачи, где человек думает и действует на экране. Профили: пошаговая игра (основной) и рабочий инструмент (набросок, проверен одним прогоном).

## Файлы

- method-brief.md - **справка**: шаги 0-8 с обязательными выходами до первого экрана и чек-лист. Её отдают другим чатам.
- method.md - метод: основание, к нему обращаются, когда спорят со справкой.
- runs/ - прогоны метода на живых задачах, по файлу на прогон. Каждый новый прогон - сюда.
- HANDOFF.md - состояние работы над методом для того, кто продолжает.

## Как отдать справку чату

Чат должен иметь доступ к этому репозиторию: он закрытый. Команда:

```
Прочитай method-brief.md из репозитория estetco-cmyk/ux-method целиком. Профиль - [игра или инструмент]. До первого макета выдай выходы шагов 0-8. Макет - только после них, каждый его элемент должен найтись в таблице шага 4 или шага 6. В конце - чек-лист из справки с ответом на каждый пункт.
```
