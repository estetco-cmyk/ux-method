# Передача: метод

15.10.2026. Для чата, который не видел, как метод появился.

## Главное

Метод - инструмент для поиска проёбов в пути игрока, не предмет исследования. Цель Анатолия - добротные билды и релиз Secredoku и игр Catchdoku.

Метод гоняют только по живому поводу: новый экран, новый блок, подготовка к релизу. Ради проверки самого метода прогонов не заводить, слабости метода не "закрывать".

Применяется через справку method-brief.md (команда - в README.md). Находки прогона идут решениями в репозиторий игры, а не вопросами Анатолию списком: чат предлагает свой ответ на каждую находку, Анатолий говорит "да" или поправляет.

## Решения Анатолия, которые не пересматриваются без него

- Предмет - взаимодействие через интерфейс. Не классификация элементов и не теория игрового опыта.
- Верхний уровень - цикл: ситуация и цель, восприятие и понимание, выбор и действие, результат и обратная связь, следующая ситуация. В трёх масштабах.
- Что есть информация (инвентарь) и как её показывать (предъявление) - разные вопросы.
- Основной профиль - пошаговые игры.
- Таблиц и классификаций без необходимости не добавлять.

## Известные слабости (помнить, не чинить)

- Справка не видит нефункциональное: заставку, атмосферу, сюжет награды. Правило "элемент без строки - лишний" такое отрежет - решать по смыслу, не по таблице.
- Если чату открыт билд, он описывает билд, а не проектирует новое.
- Ссылка на Нормана без страницы и издания - проверить, если метод уйдёт наружу.
